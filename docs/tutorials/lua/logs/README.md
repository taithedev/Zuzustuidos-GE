# Debug Lua from the status bar

**Lesson 6 / lua**

## Goal

Use print_log for small status messages while testing scripts.

## Try it

```text
function start() print_log('Script loaded') end
```

## What to know

Avoid printing every frame; the prototype only shows the most recent status message.
