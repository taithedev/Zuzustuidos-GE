# Attach a Lua file

**Lesson 2 / lua**

## Goal

Create a script under the project Assets/Scripts folder, then set LuaScript in an entity's JSON.

## Try it

```text
"LuaScript": "Scripts/floating.lua"
```

## What to know

The inspector's + Attach Lua button picks the provided floating.lua sample.
