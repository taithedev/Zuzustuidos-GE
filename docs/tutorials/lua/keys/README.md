# Read a held key

**Lesson 4 / lua**

## Goal

Check key_down with a Raylib key enum name.

## Try it

```text
function update(dt)
  if key_down('W') then translate(0,0,-3*dt) end
end
```

## What to know

This sample responds while the engine is in Play mode.
