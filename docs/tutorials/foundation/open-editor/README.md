# Run the editor

**Lesson 3 / foundation**

## Goal

From the repository folder run the Windows launcher. Linux/macOS users can use bash run.sh.

## Try it

```text
run.bat
```

## What to know

The initial run restores NuGet packages. The editor opens the StarterProject by default.
