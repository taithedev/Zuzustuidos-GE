# Diagnose SDK issues

**Lesson 6 / foundation**

## Goal

If dotnet is not recognized, check that the SDK installed and reopen your terminal.

## Try it

```text
dotnet --info
```

## What to know

If packages fail to restore, verify your network connection and rerun dotnet restore src/ZuzuStudios/ZuzuStudios.csproj.
