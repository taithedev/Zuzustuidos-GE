# Install the .NET SDK

**Lesson 1 / foundation**

## Goal

Install the free .NET 8 SDK from https://dotnet.microsoft.com/download/dotnet/8.0. Choose the SDK, not just the runtime.

## Try it

```text
dotnet --version
```

## What to know

The command must show a version. SDK is required to compile the C# editor; the game engine itself is free.
