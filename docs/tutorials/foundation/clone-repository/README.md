# Clone the repository

**Lesson 2 / foundation**

## Goal

Install Git for Windows, then clone the game engine into a writable folder. You can also use GitHub's Download ZIP.

## Try it

```text
git clone https://github.com/taithedev/Zuzustuidos-GE.git
```

## What to know

The repository includes the source code and a starter project. Do not place it under a locked system directory.
