# Back up a scene

**Lesson 5 / foundation**

## Goal

Before experimenting, copy your scene file to a separate backup folder outside Assets/Scenes.

## Try it

```text
copy projects\StarterProject\Assets\Scenes\main.scene.json main.scene.backup.json
```

## What to know

Scene JSON is plain text and friendly to version control. Commit before large changes.
