# Test the sample world

**Lesson 4 / foundation**

## Goal

Open the editor and press F5 to start Play. Use arrow keys to move Player Cube, and press F5 to stop.

## Try it

```text
F5 → Arrow keys → F5
```

## What to know

Play clones the edit scene; changes while playing do not overwrite the saved scene.
