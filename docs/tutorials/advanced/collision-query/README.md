# Check bounding-box intersections

**Lesson 1 / advanced**

## Goal

Use Physics.CollisionQueries.Overlaps(a,b) to test static entity bounding boxes.

## Try it

```text
bool touching = ZuzuStudios.Physics.CollisionQueries.Overlaps(a, b);
```

## What to know

This helper does not calculate forces, velocities or rigid-body response.
