# Launch outside Windows

**Lesson 2 / building**

## Goal

Use the bash helper on Linux/macOS when the native Raylib dependency is available.

## Try it

```text
bash run.sh
```

## What to know

This path starts the editor from source; it does not create a platform-specific installer.
