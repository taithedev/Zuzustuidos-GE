# Publish a Windows build

**Lesson 1 / building**

## Goal

Run build-windows.bat after installing .NET 8 SDK.

## Try it

```text
build-windows.bat
```

## What to know

Output appears in dist/Windows. The game's Assets folder is separate from the EXE; include it when distributing.
