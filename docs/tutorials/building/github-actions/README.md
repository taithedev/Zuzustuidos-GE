# Find the GitHub build

**Lesson 4 / building**

## Goal

Open the repository's Actions tab after a push to main.

## Try it

```text
GitHub → Actions → Build ZuzuStudios
```

## What to know

The workflow compiles on Windows and Ubuntu and publishes a Windows artifact if the Windows job passes.
