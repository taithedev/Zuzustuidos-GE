# Run project checks

**Lesson 6 / building**

## Goal

Run the included JSON validator from the repository root.

## Try it

```text
python tools/validate_project.py projects/StarterProject
```

## What to know

It checks the project manifest, scene JSON, supported primitives and referenced Lua files.
