# Start game-only mode

**Lesson 3 / building**

## Goal

Run the engine with --game to hide editor panels and start the runtime immediately.

## Try it

```text
dotnet run --project src/ZuzuStudios/ZuzuStudios.csproj -- --project projects/StarterProject --game
```

## What to know

The starter's example is not packaged as an independent game yet.
