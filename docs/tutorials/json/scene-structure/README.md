# Understand scenes

**Lesson 2 / json**

## Goal

Open projects/StarterProject/Assets/Scenes/main.scene.json. The root object contains Name and Entities.

## Try it

```text
"Entities": [{ "Name": "Cube", "Primitive": "Cube" }]
```

## What to know

Each entity can include Position, Size, Color, Visible, LuaScript and CSharpScript.
