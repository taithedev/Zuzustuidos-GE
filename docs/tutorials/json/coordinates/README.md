# Edit numeric coordinates

**Lesson 3 / json**

## Goal

Open scene JSON with VS Code or another editor, then change Position.X, Position.Y or Position.Z.

## Try it

```text
"Position": { "X": 2, "Y": 1, "Z": -3 }
```

## What to know

X is left/right, Y is up/down, and Z is depth. Restart the editor after external JSON changes.
