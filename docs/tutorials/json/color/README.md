# Use hexadecimal colors

**Lesson 4 / json**

## Goal

Set the entity Color field to a six-digit RGB hex string.

## Try it

```text
"Color": "#71BFFF"
```

## What to know

The renderer falls back to its default accent color when the hex string is invalid.
