# Save scene JSON

**Lesson 6 / json**

## Goal

Use Ctrl+S in edit mode to write the scene to the startup scene file.

## Try it

```text
Ctrl+S
```

## What to know

Saving uses a temporary file followed by replacement to avoid leaving a partially written scene.
