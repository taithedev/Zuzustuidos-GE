# Troubleshoot missing behaviors

**Lesson 6 / csharp**

## Goal

If the status bar reports an unknown behavior, check the CSharpScript property and compile the class.

## Try it

```text
"CSharpScript": "WasdControllerBehaviour"
```

## What to know

Names must exactly identify a concrete subclass of Behaviour compiled into the engine assembly.
