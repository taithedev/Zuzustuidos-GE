# Use a built-in behavior

**Lesson 1 / csharp**

## Goal

Add a CSharpScript property to an entity with a compiled behavior class name.

## Try it

```text
"CSharpScript": "PlayerController"
```

## What to know

Existing samples include PlayerController, OrbitBehaviour and BounceBehaviour.
