# Rebuild after changing C#

**Lesson 3 / csharp**

## Goal

Unlike Lua, C# behavior classes are compiled into the engine executable.

## Try it

```text
dotnet build src/ZuzuStudios/ZuzuStudios.csproj
```

## What to know

Restart the editor after updating code. Hot-loading arbitrary assemblies is not implemented.
