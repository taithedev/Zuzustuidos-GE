# Use predictable file names

**Lesson 6 / projects**

## Goal

Use stable PascalCase C# behavior class names and descriptive .lua names.

## Try it

```text
CSharpScript: PlayerController | LuaScript: Scripts/floating.lua
```

## What to know

Avoid duplicate C# behavior class names, because behavior resolution is by short class name.
