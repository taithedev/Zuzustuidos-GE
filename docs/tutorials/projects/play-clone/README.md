# Understand Play/Stop state

**Lesson 5 / projects**

## Goal

The editor clones the scene before running scripts. Stopping returns you to the original edit scene.

## Try it

```text
F5 → Play; F5 → Stop
```

## What to know

Do not expect entity positions moved during Play to remain after stopping.
