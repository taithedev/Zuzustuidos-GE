# Choose a different scene

**Lesson 3 / projects**

## Goal

Set StartupScene in your project's manifest to an existing demo scene.

## Try it

```text
"StartupScene": "Scenes/Demos/movement/orbit/main.scene.json"
```

## What to know

Restart the editor to load a different startup scene.
