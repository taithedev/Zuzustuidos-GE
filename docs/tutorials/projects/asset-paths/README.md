# Organize the Assets folder

**Lesson 2 / projects**

## Goal

Keep scenes in Assets/Scenes and Lua files in Assets/Scripts.

## Try it

```text
Assets/Scenes/main.scene.json
Assets/Scripts/floating.lua
```

## What to know

Paths stored in scene JSON are relative to Assets, not the repository root.
