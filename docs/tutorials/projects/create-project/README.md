# Start a second game project

**Lesson 1 / projects**

## Goal

Copy projects/StarterProject to projects/MyGame, then change the Name in its project.json.

## Try it

```text
dotnet run --project src/ZuzuStudios/ZuzuStudios.csproj -- --project projects/MyGame
```

## What to know

This is manual project creation; a project wizard is on the roadmap.
