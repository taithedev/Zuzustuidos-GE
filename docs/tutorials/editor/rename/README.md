# Rename an entity

**Lesson 3 / editor**

## Goal

Select an object and press F2 (or use the Rename button). Type a name and press Enter.

## Try it

```text
F2 → type name → Enter
```

## What to know

Entity names are descriptive labels. Their unique identity is stored separately in Id.
