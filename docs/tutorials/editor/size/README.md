# Change primitive dimensions

**Lesson 5 / editor**

## Goal

Select a cube or sphere, then adjust Size X/Y/Z in the right sidebar.

## Try it

```text
Inspector → SIZE → +/-
```

## What to know

Cube size uses all three axes. Sphere rendering uses Size.X as diameter.
