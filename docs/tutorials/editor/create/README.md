# Create a primitive

**Lesson 2 / editor**

## Goal

Click + Cube or + Sphere. The engine creates a 3D primitive and selects it.

## Try it

```text
Insert (cube) | Shift+Insert (sphere)
```

## What to know

These are basic built-in primitives; mesh importing is not implemented.
