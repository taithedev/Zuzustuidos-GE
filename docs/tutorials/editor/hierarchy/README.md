# Use the hierarchy

**Lesson 1 / editor**

## Goal

The left sidebar lists entities in the loaded scene. Click a row to select an entity.

## Try it

```text
Left sidebar → select Player Cube
```

## What to know

The inspector uses the selected entity. Play mode disables editing.
