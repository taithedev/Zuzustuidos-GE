# Pick an entity

**Lesson 6 / editor**

## Goal

Click a visible object in the 3D viewport to select it; the selection is outlined.

## Try it

```text
Left click object in viewport
```

## What to know

Picking uses simple bounding-box checks. Occlusion-accurate mesh picking is not yet implemented.
