# Move an entity

**Lesson 4 / editor**

## Goal

Use the inspector +/- controls for X/Y/Z position. Arrow keys adjust X/Z and PageUp/PageDown adjust Y.

## Try it

```text
Left/Right → X; Up/Down → Z; PageUp/PageDown → Y
```

## What to know

Positive Y moves upward. Position changes persist only after Ctrl+S.
