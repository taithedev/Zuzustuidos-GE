# Roadmap

## Implemented prototype

Project and scene JSON, basic 3D viewport, hierarchy, primitive inspector, orbit/fly camera, entity picking, Play/Stop, Lua and built-in C# behaviours, example project, tutorial library, and CI builds.

## Planned next

1. Asset browser, multi-scene workflow, undo/redo, GUI polish.
2. Real imported meshes, textures, materials, shaders, directional/point lights and shadows.
3. Rigid-body physics, colliders, animation, 3D audio and events.
4. C# project/hot-reload experience, advanced Lua debugging and scene prefab system.
5. Game packaging / export pipeline and plugin API.
6. OpenXR VR support and networking experiments.

None of these planned items should be described as already working.
