# Security

ZuzuStudios is an early prototype and should only be used with trusted projects and scripts. Lua scripts have a restricted API and project-root path checks, but the runtime does **not** enforce execution budgets or full isolation. C# behaviours are compiled .NET code with normal process permissions.

Do not run untrusted user projects. Report security issues privately to the repository maintainers using GitHub's security advisory reporting where available. Do not post credentials, tokens or private information in issues.
