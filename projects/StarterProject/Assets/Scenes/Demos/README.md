# Demo scenes

There are 16 alternative scenes in `Demos/<category>/<slug>/main.scene.json`. To open one, change `StartupScene` in `projects/StarterProject/project.json` to a path such as `Scenes/Demos/movement/orbit/main.scene.json`, then restart the editor. Restore `Scenes/main.scene.json` when done.

These demos use built-in, compiled C# behaviours, cubes and spheres. They do not demonstrate imported meshes or full physics.

- `Demos/showcase/primitives/main.scene.json`: A gallery of basic primitives.
- `Demos/showcase/bright/main.scene.json`: A bright prototype room.
- `Demos/showcase/minimal/main.scene.json`: A minimal world to practice editing.
- `Demos/showcase/platforms/main.scene.json`: Block platforms with scripted motion.
- `Demos/movement/walk/main.scene.json`: C# movement demonstration.
- `Demos/movement/hover/main.scene.json`: Hovering objects and platforms.
- `Demos/movement/orbit/main.scene.json`: Different orbit styles.
- `Demos/movement/timed/main.scene.json`: Ramp, wrap and pulse motion.
- `Demos/control/keyboard/main.scene.json`: Keyboard-controlled objects.
- `Demos/control/boost/main.scene.json`: Sprint when holding LeftShift.
- `Demos/control/limits/main.scene.json`: Movement limits.
- `Demos/control/arrows/main.scene.json`: Arrow-key controls.
- `Demos/routes/patrol-x/main.scene.json`: Object patrolling X axis.
- `Demos/routes/patrol-z/main.scene.json`: Object patrolling Z axis.
- `Demos/routes/zigzag/main.scene.json`: Object following a zig-zag path.
- `Demos/routes/stairs/main.scene.json`: Stair-step motion for demo primitives.
